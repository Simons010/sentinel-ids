## 2024-06-02 - N+1 query patterns in Django breakdown views
**Learning:** When optimizing N+1 query patterns in Django views that calculate frequency distributions or breakdowns (like counts per severity), replacing iterative `.filter().count()` calls with a single `.values('field').annotate(count=Count('field')).order_by()` query significantly reduces database load. However, you MUST remember to use an empty `.order_by()` to prevent default model ordering from messing up the group by logic, and you MUST pre-initialize the result dictionary with all expected keys set to zero to ensure consistent API responses.
**Action:** When calculating breakdown stats (e.g., severity counts, status counts), replace N+1 `.filter().count()` loops with an annotated `.values()` query, ensuring `.order_by()` is cleared and the result dictionary is seeded with all necessary keys.

## 2026-05-28 - Optimize N+1 queries in frequency distributions
**Learning:** When optimizing N+1 query patterns in Django views that calculate frequency distributions or breakdowns (like counts per severity), replacing iterative `.filter().count()` calls with a single `.values('field').annotate(count=Count('field')).order_by()` query is much more efficient. Also learned that when using `.values().annotate()` to aggregate or group results, it is important to include an empty `.order_by()` to clear any default model ordering that might interfere with the grouping logic, and pre-initialize the result dictionary with all expected keys set to zero.
**Action:** Always use the `.values().annotate().order_by()` pattern for frequency distributions instead of iterative `.filter().count()` calls, and ensure the dictionary is pre-initialized.

## 2024-05-26 - Icon-Only Action Buttons in Data Lists
**Learning:** When using icon-only action buttons (like a delete "X" or trash can) within recurring UI elements such as data tables or upload lists, a generic `aria-label` (e.g., "Remove") lacks sufficient context for screen reader users to identify *which* item is being targeted. This ambiguity creates a poor, unnavigable experience.
**Action:** Always construct dynamic, specific `aria-label` attributes for icon-only action buttons in lists by concatenating the action with an identifying property of the row's data (e.g., `aria-label={"Remove " + file.name}`). Additionally, mark the inner visual icon as `aria-hidden="true"` to prevent redundant or confusing screen reader announcements, and ensure keyboard focus states (`focus-visible`) are prominent.

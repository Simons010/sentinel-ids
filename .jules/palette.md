## 2024-05-18 - Improve Keyboard Accessibility of File Upload Area
**Learning:** A visually hidden (`sr-only`) file input can still be functional. However, applying focus to the parent container using `focus-within` allows for much better styling options than trying to style the `<label>` directly, especially for complex UI like dropzones. Providing a visual outline ensures users navigating with the keyboard know what element is active. Additionally, we need to handle keyboard events (`Enter`, `Space`) on the label to programmatically trigger the hidden input, because visually hiding the input removes the native keyboard interactions.
**Action:** Use `sr-only` for file inputs instead of `hidden` to keep them in the accessibility tree. Use `focus-within` on a parent wrapper, and ensure the interactive element (e.g. `label` with `tabIndex={0}`) handles `Enter` and `Space` keyboard events to programmatically trigger the hidden input.

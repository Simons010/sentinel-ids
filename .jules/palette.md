## 2025-05-18 - Contextual ARIA labels and Focus States in Data Tables
**Learning:** Icon-only action buttons in data tables (like View, Edit, Delete) need context-specific `aria-label` attributes incorporating row data (e.g., `aria-label="Delete file.txt"`) rather than generic labels (e.g., `aria-label="Delete"`). Without this context, screen reader users navigating by interactive elements will hear "Delete, Delete, Delete" and won't know which item they are acting upon. Additionally, adding `aria-hidden="true"` to inner SVG icons prevents redundant announcements, and combining `focus-visible:outline-none` with `focus-visible:ring-2` using semantic colors provides clear keyboard accessibility feedback.
**Action:** When adding icon-only buttons to lists or tables, always construct the `aria-label` using unique identifying data from the row (like filename or ID). Always hide the visual icon from screen readers using `aria-hidden="true"`, and ensure visible focus states are present for keyboard users.

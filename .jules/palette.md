## 2024-07-12 - Adding Focus and ARIA Labels to Icon-Only Buttons
**Learning:** Icon-only buttons lacking `aria-label` attributes present accessibility issues for screen reader users, and missing focus states hinder keyboard navigation. A pattern discovered for group elements (like table rows) is to use `group-focus-visible:text-[COLOR]` on the child icon, paired with `group-hover:text-[COLOR]`, while applying `focus-visible:ring-2 focus-visible:outline-none` with the appropriate ring color to the parent button element.
**Action:** Always ensure icon-only buttons receive an `aria-label` attribute and explicitly style their focus states (e.g., using `focus-visible:ring`) to match the hover interaction visually. Utilize `group-focus-visible` where appropriate to propagate focus states similarly to hover states.

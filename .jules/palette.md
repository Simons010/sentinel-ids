## 2024-05-24 - Add contextual ARIA labels to data table action buttons
**Learning:** For icon-only action buttons within data tables (like UploadHistoryTable), generic ARIA labels (e.g., 'Delete') are insufficient for screen readers because they lack context. You need to append identifying information from the row's data (e.g., `aria-label={"Delete " + item.filename}`) to ensure users know exactly what item they are acting upon. Furthermore, keyboard navigation must be supported with explicit `focus-visible` styles to give clear feedback.
**Action:** Always include item-specific context in `aria-label` attributes for icon-only buttons in lists or tables, explicitly hide the inner decorative SVGs with `aria-hidden="true"`, and provide keyboard focus indicators using Tailwind's `focus-visible:ring-2 focus-visible:outline-none`.

## 2024-05-07 - Avoid Dynamic Values in `aria-label` Attributes
**Learning:** Adding dynamic values (like unread notification counts) to static `aria-label` strings can cause screen readers to fall out of sync or improperly read state changes.
**Action:** Instead of embedding dynamic values in `aria-label` or relying solely on a tooltip, inject visually hidden text using an `sr-only` class alongside visual badges. This ensures the screen reader is properly synchronized with dynamic data.
## 2024-05-21 - Accessible Action Buttons within Tables
**Learning:** For icon-only action buttons within data tables, always append identifying context from the row's data to the ARIA label (e.g., `aria-label={"Delete " + item.filename}`) to ensure screen readers provide meaningful context instead of simply reading "Delete" repeatedly for every row.
**Action:** When adding accessible focus states to UI elements using Tailwind, combine `focus-visible:ring-2` and `focus-visible:outline-none` with an appropriate ring color to ensure clear keyboard navigation feedback. Always add `aria-hidden="true"` to the inner SVG icons to prevent screen readers from redundantly announcing the visual elements when an `aria-label` is already provided on the parent button.

## 2025-06-10 - [Critical] Hardcoded Superuser Credentials
**Vulnerability:** The `create_default_admin` Django management command contained hardcoded default credentials (username `d3fau1t`, password `d3fau1t_Password!2026`) used as fallbacks if environment variables were missing. These same default credentials were also codified in `.env.example`, `docker-compose.yml`, and documented in `README.md`.
**Learning:** Default hardcoded passwords provide a simple bypass for authentication and are a major security risk, especially when initializing critical administrative accounts. They should never be hardcoded into scripts, example files, or configuration templates, as users frequently deploy these components without changing the defaults.
**Prevention:** Rely strictly on explicit environment variables for sensitive configuration such as initialization passwords. Management scripts that create accounts should abort and fail securely with a clear error message if the required credential environment variables are not provided, instead of falling back to insecure defaults.

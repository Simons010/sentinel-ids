## 2026-08-03 - Detail API View IDOR Vulnerability
**Vulnerability:** Django REST Framework detail API views (like ReportDownloadView) were accessible by any authenticated user because they did not explicitly validate that the requested record belonged to the user making the request. Note that `IntegrationApiKey` and `TeamMember` models are global and do not have user ownership fields, so restricting them by user ownership is not applicable.
**Learning:** The default Django REST Framework permission in this project is `IsAuthenticated`. To prevent IDOR on detail endpoints that are user-owned, do not blanket apply `permission_classes = [IsAdminUser]` as it restricts access to global admins (`is_staff=True`) and breaks standard user functionality. Instead, implement object-level permissions (ABAC) by filtering the requested record against the user (e.g., `filter(pk=pk, generated_by=request.user)`).
**Prevention:** Always ensure that database queries in detail APIViews explicitly filter on the authenticated user when fetching records that belong to a specific user, to prevent Insecure Direct Object Reference (IDOR) vulnerabilities.

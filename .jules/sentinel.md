## 2024-05-24 - Missing Authentication and IDOR on Critical Endpoints
**Vulnerability:** Found `AllowAny` used on the `LogIngestView` allowing unauthenticated log flooding, and missing permission constraints on `IntegrationApiKeyDetailView` and `TeamMemberDetailView` leading to IDOR/Broken Access Control vulnerabilities where standard authenticated users could perform admin-level actions.
**Learning:** Over-reliance on global DRF permission settings or forgetting to enforce explicit permissions on new endpoints can lead to severe security gaps. `LogIngestView` needs a custom machine-to-machine authentication (API Key) rather than regular user session authentication.
**Prevention:** Always verify DRF view permissions (`permission_classes`) on every new endpoint. For automated API ingestion endpoints, implement explicit token/key validation rather than allowing public access. For administrative actions, strictly enforce role-based access control (e.g., `IsAdminUser`).

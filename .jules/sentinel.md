## 2025-02-28 - Missing Administrative Authorization on Detail Endpoints
**Vulnerability:** Insecure Direct Object Reference (IDOR) / Missing Authorization. Detail views such as `ReportDownloadView`, `IntegrationApiKeyDetailView`, and `TeamMemberDetailView` lacked explicit `permission_classes = [IsAdminUser]`, allowing any authenticated user (due to default `IsAuthenticated` DRF permission) to delete API keys, edit team members, or download reports.
**Learning:** Django REST Framework relies on the default permission setting (`IsAuthenticated`) when a view does not define its own `permission_classes`. In a codebase where collection views explicitly check for `IsAdminUser`, developers often forget to mirror those same restrictions on their corresponding detail endpoints.
**Prevention:** Always define `permission_classes` explicitly on all views, especially those performing state-changing operations (DELETE/PATCH) or accessing sensitive data (downloads), rather than relying on project-wide defaults.
